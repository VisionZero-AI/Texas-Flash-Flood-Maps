# Texas Flash Flood 2025 – Public Map Library

This repository contains **static HTML flood maps** created for public
situational awareness during the 2025 Texas flash flood events.

These maps are intended for:
- Emergency coordination
- Public understanding
- Media and research reference

## What this repository contains
- Interactive flood-risk and recovery maps (HTML only)
- No executable code
- No models or algorithms
- No raw data

## Map Versions

**Map v1 – Recovery Zones (A/B/C)**  
Highlights SAR-aligned recovery areas based on observed downstream patterns.

**Map v2 – Measurement & Inspection Tools**  
Adds distance measurement, mouse coordinates, and enhanced interaction
for responders and analysts.

## Disclaimer
These maps are not official FEMA or State products and are provided
for situational awareness only.

Designed independently by Anuar Aubakirov.
